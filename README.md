# Manga Nova 📚

## خطوات رفع المشروع على GitHub

### 1. أنشئ Repository جديد
- اذهب إلى github.com
- اضغط New Repository
- اسمه: manga-app
- اختر **Private** ✅
- اضغط Create

### 2. ارفع الملفات
اسحب كل ملفات المشروع وارفعها على GitHub

### 3. انتظر البناء
- اذهب إلى تبويب **Actions**
- انتظر دقيقتين تقريباً
- اضغط على **manga-nova-apk** لتنزيل الـ APK ✅
